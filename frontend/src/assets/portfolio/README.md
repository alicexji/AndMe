# Your art collection

Drop artwork images into this folder: `frontend/src/assets/portfolio/`.

- Supported: JPG, JPEG, PNG, WebP, GIF, and AVIF (including uppercase extensions).
- Subfolders work too. Images are ordered alphabetically by path.
- Filenames become captions: `01-blue-contours.jpg` becomes `01 blue contours`.
- During `npm run dev`, adding or removing an image updates the gallery automatically.
- For a production site, rebuild with `npm run build` after changing the collection.
- Export HEIC photos as JPG or PNG first.

Open the Portfolio tab and click any image to view it larger. Escape closes the viewer.
